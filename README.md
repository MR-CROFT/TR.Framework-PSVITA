# TR.Framework-PSVITA
A fan-made Unity gameplay framework that recreates the core mechanics of Tomb Raider: The Angel of Darkness, with PSVita as its primary development platform. Built using Uraider 2018 (v1) character controller but heavily expanded to include inventory, AI, stealth, lock and key systems, and more — closely resembling the original PS2 gameplay experience.

🕹️ Platforms
✅ Primary: PlayStation Vita (PSVita)
✅ Secondary: PC (Export-ready)

🎯 The Unity project is configured for PSVita by default.
You have 4 levels to play and explore. Three (ParisTutorial, Paris and ParisFinal) are complete, the fourth (Prague) is not.

⚙️ Requirements
To build or run this project for PSVita, you will need:

🔧 Unity
Unity 2018.2.19f1 (last Unity version officially compatible with PSVita SDK),
PSVita SDK,
Unity PSVita Editor Support,
PSVita Video Player Plugin (used for pre-rendered cutscenes)

💻 Optional for PC builds: 
Unity Standalone Build Support (Windows)

🎮 Features

🎯 Core Gameplay Systems
☑️ Basic Lara Croft character controller (Uraider 2018 base - upgraded)
✅ Freeclimb functionality (new)
✅ Climbing & hanging variations (new)
✅ Push/Pull system for movable objects (new)
✅ Swimming system with breath meter (new)
✅ HP (health system) (upgraded)

🧠 Enemy & AI
✅ Enemy patrol and detection system (new)
✅ Enemies can arrest or attack Lara (new)
✅ Stealth mode (affects AI perception) (new)
✅ Enemies drop items after being eliminated (new)

🔫 Combat System
✅ Basic combat logic (crosshair similar to TR Legend) (new)
⚠️ Weapons/ammo pickup system not implemented yet

🎒 Inventory & Interaction
✅ Inventory system (TR1–3) (upgraded from Uraider, now replicates TR Menu Perfectly with Item Menu, Consumables and System Menu)
✅ Combine items functionality (new)
✅ Consumables (e.g., medkits) (new)
✅ Lock and Key mechanic (new)
✅ Lever system to open doors (new)
✅ Search system: interact with drawers, cabinets, etc. (new)
✅ Underwater item pickup (new)
✅ AOD-style door opening system with SFX (new)
